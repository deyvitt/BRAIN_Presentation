⚠️
Limitation 1: Temporal Inconsistency

DiT models (SeeDance, Stable Video) generate each clip independently. Character's face, clothing, or background shift dramatically between consecutive prompts — no persistent identity.

🧑 Example: "Hero with red cape" → next clip: blue cape, different face shape. No memory.
⚡
Limitation 2: No Object Permanence

If an object moves off-screen and returns, DiT regenerates it from scratch — often with different appearance, breaking narrative logic.

📦 Example: A ball rolls behind a box → reappears as a cube. DiT forgets.
🧠
BRAIN for DiT: VNI Memory Tokens

BRAIN injects Viral Neural Impressions into DiT latent space. Each character/scene gets a persistent VNI that conditions all future frames — cross-session memory.

✅ Same red cape, same face, even after 100+ frames. Object reappears identical.
🔄
Hebbian Learning for Style Locking

User feedback (“keep this lighting”) strengthens VNI weights. Negative feedback weakens irrelevant features. DiT adapts without fine-tuning.

🎨 One-click style locking: cinematic noir → VNI cements mood across scenes.
